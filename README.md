# МТС Energytool - ИИ-консультант (Django)

Чат-консультант на сайте: ведёт клиента от описания задачи до заявки менеджеру.

## Архитектура
- `chat/service.py` - вся бизнес-логика: загрузка базы знаний (все пространства имён: `00-reference`, `10-energy`, `20-products`),
  гибридный поиск (BM25 + эмбеддинги bge-m3 + реранкер), генерация ответа, сбор контактов, создание заявки и резюме.
- `chat/views.py` - тонкий слой: `GET /` (чат), `POST /api/chat/`, `POST /api/new/` («Новый диалог»).
- `chat/models.py` - `ChatSession` (диалог), `Message` (реплики, время ответа, документы базы), `Lead` (заявка: ФИО, телефон, компания, резюме, статус).
- `chat/admin.py` - панель `/admin/`: заявки и история всех диалогов, в том числе без заявки.

## Запуск (одна команда)
1. `cp .env.example .env` и заполните переменные (адрес и ключ LLM-прокси, пароль администратора).
2. Положите `knowledge-base.zip` в `data/` (в репозиторий не коммитится).
3. `docker compose up --build`

Чат: http://localhost:8000/ - Админка: http://localhost:8000/admin/

## Сценарий проверки
1. Опишите задачу («хотим солнечную станцию, вечером тратим больше всего»), бот задаёт уточняющие вопросы.
2. Включите «Режим отладки» - под ответами видно время ответа и использованные документы базы.
3. Согласитесь на контакт и назовите ФИО, телефон, компанию (тестовые данные) — появится «Заявка передана менеджеру».
4. В `/admin/` откройте «Заявки» (резюме и полный диалог) и «Диалоги».
5. «Новый диалог» полностью сбрасывает контекст; старый диалог остаётся в базе.

## Возможная проблема
Если возникают проблемы программы с подключением к внешним моделям, потребуется изменить файлы.

Для файла 'compose.yaml' добавьте сервис:
```
app:
 build: .
 env_file: .env
 extra_hosts:
  - "host.docker.internal:host-gateway"
```
Тогда для файла '.env' измените пути к моделям. Вот один из примеров:
```
LLM_BASE_URL=http://host.docker.internal:11434/v1
LLM_API_KEY=ollama
LLM_MODEL=qwen/qwen3.8-27b
EMB_MODEL=baai/bge-m3
# RERANKER_MODEL=qwen/qwen3-reranker-8b
```
После этого вернитесь к пункту *Запуск (одна команда)*

## Встраивание в сайт
Чат отдаёт страницу без запрета фреймов: `<iframe src="https://<хост>/" style="width:420px;height:640px;border:0"></iframe>`.
Заявки сохраняются в БД проекта.

## Переменные окружения
`LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`, `EMB_MODEL`, `RERANKER_MODEL`, `TOP_K`, `RERANKER_TOP_N`, `MAX_TOKENS`, `TEMPERATURE`,
`MAX_WORKERS`, `KB_PATH` (по умолчанию `data/knowledge-base.zip`), `DB_PATH`, `WARMUP` (прогрев индекса при старте, по умолчанию 1), `DJANGO_*`.

## Известные ограничения
- Индекс базы знаний строится в памяти при старте (эмбеддинги запрашиваются у прокси), первые секунды после запуска ответы могут быть медленнее.
- SQLite подходит для прототипа; для продакшена можно использовать другую БД в `config/settings.py`.
